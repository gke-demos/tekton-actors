Unit of Operation 1 Trunk Workspace Actor + 3 CoW Branch Actors (`0` PVCs, `0` AffinityAssistant pods) 5 Kubernetes Pods + 1Gi RWO PVC + 1 AffinityAssistant StatefulSet
Sequential Toolchain Handoff SuspendActor → UpdateActor(actor_template) → ResumeActor (SNAPSHOT_FIDELITY_VOLUMES) Full Pod teardown & kubelet volume re-mount on the pinned RWO node
Parallel DAG Fan-Out Immutable milestone Snapshot Tag (ms-*) + isolated copy-on-write Branch Actors on any warm worker Shared mutable RWO filesystem forced onto a single node by AffinityAssistant
